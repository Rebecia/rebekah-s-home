# 更新记录

本项目版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.2.0] - 2026-08-31

面向 VS Code 插件市场做的一轮调整：任何一个装着 Markdown 卡片的文件夹都能用，不再假设装了 Comate。

### 新增

- 首次运行引导：没指目录或目录里没有卡片时，三个视图都显示引导块，可直接「选择卡片目录」或「创建示例卡片」
- 命令 **Personal KB: 选择卡片目录**、**Personal KB: 创建示例卡片**（示例卡片本身就是格式说明）
- 单测覆盖到 7 项，新增「vault 里已有同名真实文件夹时不覆盖也不删除」「示例卡片可解析且重复调用不覆盖已改内容」

### 变更

- 定位与文案从「Comate personal-kb 的阅读层」放宽为「一个文件夹的 Markdown 卡片墙」，Comate 沉淀降级为可选来源
- `personalKb.kbPath` 成为一等配置，留空才回退到 Comate 默认路径
- 命令 **在 Finder 中显示知识库** 改名为 **在文件管理器中显示卡片目录**（原文案是 macOS 专属）
- 去掉启动时的「未找到卡片目录」警告弹窗，改为视图内引导

### 修复

- Windows 上创建 Obsidian 软链遇到 EPERM 会直接抛异常；现在捕获并提示需要开发者模式或管理员权限
- 卡片目录原本不存在时文件监听不生效，之后创建目录也不会自动刷新；现在会盯住父目录并自动重挂
- 删除软链失败（权限等）不再被误报成「不存在」

## [0.1.0] - 2026-08-28

首个可打包版本，尚未上架。

### 新增

- 活动栏 **Personal KB**：统计视图 + 卡片列表视图（均为 webview）
- 命令 **Personal KB: 打开卡片墙**：bento 布局的卡片墙，点开看结论 / 为什么重要 / 怎么用 / 反例
- 统计：已沉淀、本周新写、待复习三项指标，分类分布环形饼图
- 卡片列表按月分组，支持按类型筛选与关键词搜索；卡片墙内标签可点筛选
- **连接到 Obsidian vault**：在 vault 根目录创建软链 `Personal-KB` 指向 `kb/`，两边同一份文件
- 文件监听：`kb/` 下的 Markdown 变化后自动刷新
- 配置项 `personalKb.kbPath`、`personalKb.obsidianVault`
- 预留 flomo / 思源 / Notion / 印象笔记 连接器接口（一期未接通）
