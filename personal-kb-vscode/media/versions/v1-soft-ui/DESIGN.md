# 阅读层视觉

用户否决了楷体+斜章（太古典），也否决了当代阅读流+荧光划线（更丑）。
这一版按用户上传的健康 dashboard 参考图复刻：软 UI 磁贴。

frontend-design 的规则：brief 指定了方向时，brief 的原话优先于反模板默认值。

## 产品

一屏看清「有多少、什么类型、这周写了几张、哪些该复习」，点开才读全文。

## Token（theme.css）

- 页面底 `#ECEEED` / dark `#14171B`
- 磁贴三种填色轮换：白 `--tile` / 奶油 `--cream` / 天蓝 `--sky`
- 圆角 26 / 20 / 14，双层柔和阴影 `--shadow`
- 字体：Poppins → Avenir Next → PingFang SC，标题 700 字重
- 六类各一个颜色，落在 30px 圆形 `.badge` 上（思/基/i/错/生/术）

## 签名

- 圆形彩色 badge + 大数字配小单位（`9` + `张`）
- 胶囊导航，激活态填 `--sky-strong`
- 主操作是深色胶囊 `.go`
- 分类分布用纯 CSS 条形图

## 不要

楷体、印章、报纸栏、荧光划线、玻璃拟态、渐变、hover 位移。
