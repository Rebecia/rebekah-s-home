# 阅读层视觉

## 当前版本 v3 — token 立住 + 中文排版修正

底子还是 v2 的单色磨砂（银白面 + 暖光斜纹 + 半透玻璃 + 黑胶囊），v3 改的是让它「不糙」的那几件事。

### 规则

**视图 CSS 只允许引用 theme.css 的 token，不准自己写数值。** 之前每个视图各写一套 px，所以怎么调都对不齐。

- 字号五档：`--t-hero 28 / --t-h1 20 / --t-h2 15 / --t-body 13 / --t-note 11`
- 间距 8pt 阶梯：`--s1 4 / --s2 8 / --s3 12 / --s4 16 / --s5 24 / --s6 32`
- 圆角两档：`--r-md 14 / --r-lg 20`
- 阴影两档：`--sh-1` 静止 / `--sh-2` hover 与浮层
- 字色三档：`--ink / --mute / --faint`

### 中文排版

- 字体栈以 `-apple-system → SF Pro Text → PingFang SC` 为主。不混 Inter：Inter 没有中文字形，中英会落到两套不同基线的字体上，这是 v2 显糙的主因。
- `letter-spacing: 0`，正文行高 1.7、卡片摘要 1.75–1.8。负字距是拉丁字体的技巧，套在方块字上是挤在一起。
- 标题不再用 700，一律 600 —— PingFang 的 Semibold 比 Bold 干净。
- 只有数字用 `.num`（SF Mono + tabular-nums + 轻微负字距），仪表感来自这里。

### 层次

- 侧栏卡片列表按月分组，组标题带一条延伸细线
- 分类分布是环形饼图（`conic-gradient` + `mask` 挖空，中心放总数），配色是单色灰阶递减，最大一块用琥珀；不用条形图
- 卡片墙第 1 张是 feature（跨 2 列 2 行，标题 28px），第 4 张跨 2 列
- 标签可点，点了等于按该标签搜索
- 状态齐了：hover 抬阴影 + 边框加深、`:focus-visible` 琥珀色焦点环、虚线框空态

### 不要

彩色圆形 badge、奶油/天蓝填色磁贴（v1）、中文负字距、Inter 混排、楷体、印章、报纸栏、荧光划线、渐变按钮、hover 位移。
